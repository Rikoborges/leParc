Structure HTML5 Sémantique index.html
La page utilise des balises sémantiques HTML5 pour structurer le contenu de façon logique et lisible par les moteurs de recherche. Chaque section possède un rôle précis : <header> pour l'en-tête, <nav> pour la navigation, <main> pour le contenu principal, <section> pour chaque bloc thématique et <article> pour chaque carte produit. 
<!-- ========== EN-TÊTE PRINCIPAL DU SITE ========== -->
<header class="main-header">
    <h1 class="brand-logo">LE PARC</h1>
    <p class="subtitle">BAR & TABAC</p>

    <!-- Navigation : sélecteur de langue + réseau social -->
    <nav class="lang-selector">
        <button>FR 🇫🇷</button>
        <button>PT 🇧🇷</button>
        <button>AR 🇸🇦</button>
    </nav>
</header>

<!-- Section hero : accroche principale de la page -->
<section class="hero-section" id="hero">
    <h2>Votre bar incontournable au cœur de Valence</h2>
    <a href="#menu">Voir la carte</a>
</section>

<!-- Contenu principal : la carte du bar -->
<main class="menu-container" id="menu">

    <!-- Bloc thématique : cocktails signature -->
    <section class="category-block">
        <h3>COCKTAILS SIGNATURE</h3>

        <!-- article = unité de contenu indépendante (carte produit) -->
        <article class="menu-card">
            <div class="photo-frame"></div>
            <div class="card-content">
                <span>🍹 Caïpirinha Classique</span>
            </div>
        </article>
    </section>

</main>

<!-- Pied de page : mentions légales et informations RGPD -->
<footer class="footer-legal">
    <p>© 2026 LE PARC VALENCE. Tous droits réservés.</p>
    <p class="privacy-text">
        Conformément au RGPD, ce site ne collecte aucune donnée personnelle.
    </p>
</footer>
Balises utilisées

  • <nav>
  • <section>
  • <main>
  • <article>
  • <footer>
  • <h1> → <h3>

Accessibilité – Attributs ARIA index.html
Pour rendre le site accessible aux utilisateurs de lecteurs d'écran, j'ai ajouté des attributs ARIA sur l'ensemble des éléments interactifs et décoratifs. aria-label décrit l'action de chaque bouton, aria-hidden="true" masque les icônes décoratives, et aria-expanded / aria-controls rendent la FAQ entièrement navigable au clavier. 
<!-- Navigation : aria-label décrit la zone pour les lecteurs d'écran -->
<nav aria-label="Langue et réseaux sociaux">

    <!-- Lien réseau social : libellé explicite pour les non-voyants -->
    <a href="https://facebook.com/..."
       aria-label="Visiter la page Facebook de Le Parc">
        <!-- aria-hidden : l'icône est décorative, on la masque aux lecteurs d'écran -->
        <i class="fab fa-facebook" aria-hidden="true"></i>
    </a>

    <!-- Boutons de langue : chaque bouton a un label dans sa propre langue -->
    <button aria-label="Changer la langue en Français">FR 🇫🇷</button>
    <button aria-label="Mudar idioma para Português">PT 🇧🇷</button>
    <button aria-label="تغيير اللغة إلى العربية">AR 🇸🇦</button>
</nav>

<!-- Section avec un libellé de zone explicite -->
<section class="faq-section"
          aria-label="Questions fréquentes sur Le Parc">

    <!-- FAQ interactive : aria-expanded indique si la réponse est ouverte -->
    <button class="faq-question"
            aria-expanded="false"
            aria-controls="faq-a1">
        <span>Quels sont vos horaires d'ouverture ?</span>
        <!-- Icône décorative masquée aux lecteurs d'écran -->
        <span class="faq-icon" aria-hidden="true">+</span>
    </button>

    <!-- Réponse liée au bouton via aria-controls / id -->
    <div class="faq-answer" id="faq-a1" hidden>
        <p>Le Parc est ouvert du mardi au dimanche.</p>
    </div>

</section>
Attributs ARIA utilisés
  • aria-label
  • aria-hidden="true"
  • aria-expanded
  • aria-controls
  • role="img"
  • role="list"

Responsive Design – Media Queries CSS style.css
Le site s'adapte à tous les écrans grâce à la balise <meta name="viewport"> et à trois points de rupture CSS. Sur mobile, la barre CTA fixe s'affiche en bas, les grilles passent en colonne unique et les boutons occupent toute la largeur disponible. 
/* Viewport : adapte le rendu à la taille réelle de l'écran mobile */
/* <meta name="viewport" content="width=device-width, initial-scale=1.0"> */

/* ================================================
   RESPONSIVE OVERRIDES – 3 points de rupture
   ================================================ */

/* --- Desktop (≥ 768px) : masquer la barre CTA fixe du mobile --- */
@media (min-width: 768px) {
    .sticky-cta {
        display: none;     /* barre fixe inutile sur grand écran */
    }
    body {
        padding-bottom: 0;  /* supprime l'espace réservé à la barre */
    }
}

/* --- Tablette (≤ 768px) : grille en colonne unique --- */
@media (max-width: 768px) {
    .testimonials-grid {
        grid-template-columns: 1fr;  /* 3 colonnes → 1 colonne */
        max-width: 420px;
        margin: auto;
    }
    .contact-grid {
        grid-template-columns: 1fr;  /* 2 colonnes → 1 colonne */
    }
    .hero-headline {
        font-size: 1.85rem;          /* titre réduit pour tablette */
    }
}

/* --- Mobile (≤ 480px) : boutons pleine largeur, titres compacts --- */
@media (max-width: 480px) {
    .hero-headline {
        font-size: 1.55rem;          /* titre encore plus compact */
    }
    .hero-ctas {
        flex-direction: column;      /* boutons empilés verticalement */
        align-items: center;
    }
    .btn-primary,
    .btn-secondary {
        width: 100%;                /* pleine largeur sur petit écran */
        max-width: 280px;
        justify-content: center;
    }
    .about-badges {
        grid-template-columns: 1fr;  /* 2 badges → 1 par ligne */
    }
}
Points de rupture
  • min-width: 768px → Desktop
  • max-width: 768px → Tablette
  • max-width: 480px → Mobile
